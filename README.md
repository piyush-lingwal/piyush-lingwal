## 🚀 Flagship Projects
 
### 🧠 Chanakya AI
> *AI that reads, understands, and grades handwritten Indian-language answer sheets*
 
The education system is broken for millions of students writing exams in Hindi, Telugu, Bengali. Chanakya AI fixes the bottleneck — automated, fair, multilingual evaluation at scale.
 
```
Stack: Sarvam Vision · Sarvam-105B · Akshar OCR · FastAPI · Next.js
       Spatial Grounding · Handwriting Recognition · Grading LLM Pipeline
```
 
**What makes it different:** Built natively for Indian languages. Not a wrapper — a full evaluation pipeline with spatial annotation, OCR, and rubric-grounded scoring.
 
---
 
### 🛸 AeroFlex Drone *(Graph-E-Thon 3.0 — Graphic Era University)*
> *Hot-swappable payload drones with live cloud telemetry*
 
Built as Cloud/AI Lead at a 72-hour hackathon. AeroFlex is a modular drone platform where payload modules (camera, cargo, sensors) swap without reconfiguration.
 
```
Stack: Raspberry Pi 3B · GStreamer → AWS Kinesis Video Streams
       AWS S3 (snapshots) · DynamoDB (GPS + Air Quality)
       Flask API (cargo release) · Leaflet.js · HLS.js · Chart.js
```
 
**What I built:** End-to-end cloud pipeline from drone to browser dashboard — real-time video, live GPS maps, sensor charts, and remote payload control.
 
---
